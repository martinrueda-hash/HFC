Scoring method and weights

Market size is scored on a log scale. Profitability, competitive intensity, channel access and product fit are qualitative 1–5 scores from the data file (5 = most favourable for HFC). Renovation and new build growth use the market projections for the next 5 years. The diagonal zone lines sit where attractiveness + ability to win equals the thresholds below. Changes apply immediately and are kept in this browser only.

Update the figures

Paste or load a CSV with one row per country and end market. The first line must be the header below; percentages are plain numbers (3.2 = 3.2%). Imported data stays in this browser. To change the figures for everyone, edit data.js in the repository.
